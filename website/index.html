A few things to know.

Still curious? The README covers everything in detail.

How do I turn Cappy on?

After installing, open System Settings → Keyboard → Text Input → Edit, press +, find Cappy under English and add it. Then choose Cappy from the Input menu in the menu bar.

Does Cappy send my typing anywhere?

No. Cappy has no network access, no analytics and keeps no typing history. Its timing diagnostics only record aggregate durations, never text.

When does a correction happen?

When a space commits a word or Tab completes it. Enter never triggers a correction, and line breaks and pasted text pass straight through.

How do I undo a correction?

Press Backspace right away, click Undo in the capsule, or press ⌃⌥Z while the capsule is visible. Your original word comes back exactly as typed.

How do I stop it changing a word?

Undo it twice and Cappy will ask whether to stop. You can also add the word to Protected Words in Cappy Settings.

Does it need Accessibility permission?

Not for corrections. Accessibility is optional and only used for precise word highlights in web-based editors like Discord.

Which language does it support?

British English, using the macOS dictionary plus a small local language model.

Which macOS versions are supported?

macOS 13 Ventura or later.
